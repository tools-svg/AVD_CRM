# Ndurance CRM – User Guide

## What Is This Application?
Ndurance CRM is a web‑based tool that helps you keep track of **projects** and the **tasks (modules)** that make up each project. You can assign employees, set priorities, and see the progress of every piece of work.

---

## Getting Started (no technical knowledge needed)
1. **Open the application** – Visit the URL provided by your administrator (e.g., `https://crm.example.com`).
2. **Log in** – Use the username and password given to you. If you forget them, contact your IT support.
3. **Dashboard** – After logging in you land on the **Home** page which lists all projects you have access to.

---

## Main Features
### 1. Viewing a Project
- Click on a project name in the list to open the **Project Details** page.
- At the top you see the **project title**, **description**, **status**, **company**, **start date**, **deadline**, and **priority**.
- Below are three sections:
  1. **Employee Allocation** – Shows who is assigned to the project.
  2. **Modules** – Small cards showing each module name. You can scroll left/right if there are many.
  3. **Settings** – Allows you to change status, company, dates, and priority.

### 2. Editing a Project
- On the **Project Details** page, click the **Edit** button (pencil icon) – you will be taken to the **Project Update** screen.
- **Change the status** – Use the drop‑down next to *Project Lifecycle Status* (e.g., *In Progress* → *Review*).
- **Change the company** – If you belong to more than one company, select the appropriate one from the *Sub‑Company Domain* drop‑down.
- **Edit dates** – Click the calendar icons next to *Start Date* and *End Date* to pick new dates.
- **Set priority** – Click one of the four colored circles (Low, Medium, High, Urgent).
- **Edit modules** –
  - To rename a module, click inside its name field and type a new name.
  - To add a new module, type a name in the **Add New Module** box at the bottom of the module list and press **Enter** or click **Add Stream**.
  - To remove a module, click the **X** button on the right side of the module card.
- **Assign employees** – Use the *Assign* dropdown under *Employee Allocation* to add a team member, then click **Assign**.
- **Save** – Click **Save & Update Project** at the bottom to store all changes.
- **Discard** – Click **Discard Changes** if you want to revert to the original data.

### 3. Completing a Project
- When a project is finished, click the **Complete Project** button. The system will automatically set the status to *Closed* and lock further edits.

## Frequently Asked Questions (FAQ)
| Question | Answer |
|----------|--------|
| *I can’t see my project.* | You may not have permission for that company. Ask your manager to grant access. |
| *How do I add a new employee?* | Employees are added by the admin in the **Users** section of the admin portal (outside this guide). |
| *What does the coloured priority dot mean?* | It indicates urgency: **Green** = Low, **Yellow** = Medium, **Red** = High, **Dark Red** = Urgent. |
| *Why is the **Save** button disabled?* | You have unsaved changes, or required fields (title, at least one employee) are missing. |
| *Can I export the project data?* | Yes – the admin can generate CSV reports from the **Reports** menu. |

## Tips & Best Practices
- **Always set a start and end date** – this helps the team see timelines clearly.
- **Assign a lead** – the first employee you add becomes the project lead.
- **Update status regularly** – keep stakeholders informed of progress.
- **Use the priority slider** – it visually shows how urgent a project is.
- **Do not delete modules** unless they are truly obsolete – historical data may be needed for audits.
